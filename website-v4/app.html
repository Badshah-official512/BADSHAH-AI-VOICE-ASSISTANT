Help / FAQ
Aam sawalon ke jawab
Voice call kaise start karoon?

Call tab dabao. Agar pehli dafa hai to apni free Gemini key dalni hogi — Google AI Studio se free milti hai (API Keys wale page par poori guide hai). Key sirf tumhare phone mein rehti hai.

Chat ke liye key kyun nahi chahiye?

Chat owner ki keys par sab ke liye free chalti hai. Sirf live voice call tumhari apni key par hoti hai, taake har user apni free quota use kare aur call kabhi band na ho.

BADSHAH meri baatein yaad rakhta hai?

Sirf wo baatein jo tum kaho "yaad rakho" — ya jo tum Memory page par khud add karo. Memory page se har yaad dekh, edit aur delete kar sakte ho. Memory band bhi kar sakte ho.

Call ke doran phone control kaise kaam karta hai?

Call mein bas bolo: "WhatsApp kholo", "torch on karo", "volume barhao" — BADSHAH Android app ke zariye kar dega. Ye sirf app mein chalta hai, website par nahi.
